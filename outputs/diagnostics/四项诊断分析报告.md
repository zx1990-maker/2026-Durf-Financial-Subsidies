# 全A股反事实预测 — 四项诊断分析报告

## 实验设定

| 项目 | 说明 |
|------|------|
| 训练样本 | 全A股民营企业，2014-2024 panel，27,722 obs（有效特征），3,471 firms |
| 目标样本 | CSI500 SOE (178 firms) + CSI1000 SOE (331 firms)，2024→2025 |
| 结果变量 | EBI/A = (归母净利润 + 利息支出) / 资产总计 |
| 主模型 | Ridge (α=10)，预先由民企样本内部选定 |
| 交叉验证 | GroupKFold by firm_id, 5 folds |
| 特征 | FirmSize, AssetTurnover, FinancialLeverage, FixedAssetsRatio, CurrentRatio, CapexRatio, WorkingCapitalRatio, MarketShare, HHI + 行业FE |

**所有模型选择、超参数调优、特征选择仅在民企样本内部完成。未使用SOE实际EBI/A进行任何模型调整。**

---

## 一、系统 Bias 检验

### 1.1 总体 OOF 指标（民营企业内部 GroupKFold）

| 指标 | 数值 |
|------|------|
| **OOF Mean Error (ME)** | **+0.0001** |
| Clustered SE (by firm_id) | 0.0006 |
| 95% CI | [−0.0011, +0.0012] |
| t-statistic | 0.096 (p = 0.923) |
| OOF MAE | 0.0383 |
| OOF RMSE | 0.0503 |
| Residual SD | 0.0503 |
| Residual median | +0.0003 |
| 5% / 25% / 50% / 75% / 95% | −0.0800 / −0.0250 / +0.0003 / +0.0259 / +0.0807 |
| 正残差比例 | 49.2% |
| 负残差比例 | 50.8% |

**结论：模型在民企样本上无系统偏差。ME = +0.01pp，95% CI 以零为中心，p = 0.923。**

### 1.2 Calibration Regression

```
actual = 0.0011 + 0.9778 × predicted
```

| 参数 | 估计值 | 聚类SE | 检验 | p-value |
|------|--------|--------|------|---------|
| α (intercept) | +0.0011 | 0.0013 | α = 0 | 0.390 |
| β (slope) | 0.9778 | 0.0218 | β = 1 | 0.308 |
| 联合检验 | — | — | α=0, β=1 | 0.542 |

**结论：模型校准良好。α 不显著异于 0，β 不显著异于 1。联合 Wald 检验 p = 0.542，不能拒绝完美校准的零假设。**

### 1.3 SOE-like 民企子样本

| 子样本 | n (obs) | firms | ME | SE | 95% CI |
|--------|---------|-------|-----|-----|--------|
| Top 20% PS（propensity score最高） | 9,300 | 1,037 | **−0.0097** | 0.0010 | [−0.0117, −0.0076] |
| 5-NN matching（最近邻匹配） | 5,601 | 616 | **−0.0054** | 0.0013 | [−0.0080, −0.0028] |

**关键发现：SOE-like 民企的 OOF 偏差为负值（−0.97pp）——模型反而略微低估了"长得像SOE"的民企的EBI/A。这意味着 SOE 的 positive gap（+2.82pp, +2.59pp）不能被模型偏差解释；若考虑偏差方向，真实 gap 可能更大。**

### 1.4 分组 Bias

按行业、年份、规模分组的结果已保存至 `subgroup_bias.csv`。

### 1.5 模块一结论

| 问题 | 回答 |
|------|------|
| 模型总体是否存在显著系统偏差？ | **否。ME = +0.01pp，p = 0.923** |
| 偏差的绝对值是多少？ | **0.01pp（可忽略）** |
| SOE-like 民企中偏差更大？ | **否。偏差为 −0.97pp，方向与 SOE gap 相反** |
| SOE gap 能否被该偏差解释？ | **否。Gap 约为 +2.6-2.8pp，远大于偏差的绝对值** |

## 三、Placebo Gap 检验

> 200 次迭代，分层匹配 SOE 的行业分布。

### 3.1 Placebo 结果

| 指标 | CSI500 | CSI1000 |
|------|--------|---------|
| **Real Gap** | **+2.82pp** | **+2.59pp** |
| Placebo Mean | +0.28pp | +0.38pp |
| Placebo SD | 0.34pp | 0.29pp |
| Placebo 95% CI | [−0.37pp, +0.98pp] | [−0.21pp, +0.94pp] |
| **Empirical p (one-sided)** | **0.005** | **0.005** |
| **Empirical p (two-sided)** | **0.005** | **0.005** |
| z_placebo | +7.44 | +7.64 |
| **Bias-corrected Gap** | **+2.54pp** | **+2.21pp** |

### 3.2 Placebo 是否居中于零

| 检验 | CSI500 | CSI1000 |
|------|--------|---------|
| Placebo mean | +0.28pp | +0.38pp |
| H0: mean=0 test | t ≈ 11.8, p < 0.001 | t ≈ 18.5, p < 0.001 |

**Placebo mean 略微偏离零（+0.28pp, +0.38pp），但远小于真实 gap。经偏差校正后 gap 仍为 +2.54pp 和 +2.21pp，方向不变。**

### 3.3 模块三结论

| 问题 | 回答 |
|------|------|
| Placebo gap 是否接近零？ | **均值约为 +0.3pp，虽统计上异于零但经济上很小** |
| 真实 gap 在 placebo 分布的位置？ | **远在 placebo 分布的右尾之外（z > 7）** |
| Empirical p-value？ | **0.005（200次中无一超过真实值）** |
| 真实 gap 是否只是跨样本预测的机械偏差？ | **否。Placebo 方法产生的偏差仅 +0.3pp，真实 gap 约 +2.6pp** |

## 六、总体判断

### 6.1 证据综合

| 维度 | 结论 |
|------|------|
| **预测偏差** | 模型无系统偏差（OOF ME = +0.01pp）。SOE-like 民企偏差为负（−0.97pp）。Gap 不能被模型偏差解释。 |
| **共同支持** | SOE 与民企在协变量上高度可区分（AUC=0.925）。仅 26.5% SOE 有良好支持。但限制支持集后 gap 方向与量级稳定。 |
| **Placebo** | Placebo gap ≈ +0.3pp（虽统计上异于零但经济上很小）。真实 gap 远在 placebo 分布之外（empirical p = 0.005）。 |
| **Bootstrap** | CSI500 95% CI = [+2.06pp, +3.37pp]；CSI1000 95% CI = [+1.85pp, +3.01pp]。两者均不包含零。 |

### 6.2 主要结论

1. **证据支持 subsidy gap 显著大于零**：Bootstrap 95% CI 不包含零，Placebo 检验 p = 0.005，OOF 偏差接近零。

2. **该结论主要受共同支持不足影响**：仅 26.5% SOE 处于良好共同支持区间，CSI500 仅 9.6%。但这是一个"保守"的局限——模型对 SOE 的预测实际上是外推，而外推方向恰好产生正 gap，可能夸大了真实差异。

3. **主结果**：Bias-corrected gap CSI500 ≈ +2.54pp，CSI1000 ≈ +2.21pp，Bootstrap 95% CI 不包含零。

4. **探索性结果**：行业拆分、按所有制拆分、CSI300 vs CSI500 vs CSI1000 对比。这些受样本量限制更严重。

5. **建议**：应对原始 gap 做 placebo bias correction（−0.3pp 校正），并限制到 common-support SOE 子集作为稳健性检验。

6. **CSI500 的共同支持远差于 CSI1000**：CSI500 的 gap 估计可能更不可靠（外推成分更大），虽然 gap 量级与 CSI1000 相近。
