# 共同支撑域重算结论（5-NN vs 5-NN vs 旧方法）

生成日期：2026-08-20。本文件只报告数字变化，不改动论文正文、不重新解释经济机制。

**核心结论（率差口径稳健，金额分解口径高度敏感）**

1. Full gap 完全未变：All SOE 2019–2025 **+2.02 pp [1.82, 2.21]**，cluster bootstrap 与 task08 逐位复现，确认本任务未改动任何 gap、未重训任何模型。
2. 共同支撑域在 5-NN-vs-5-NN 下明显放宽：All SOE 的 CS 占比 **75.5% → 90.2%**、外推占比 **24.5% → 9.8%**；9,078 个 SOE-year 中有 **29.4%** 改变了支撑分类（2025 年外推企业数 359 → 149 家）。
3. 率差核心指标结论不变：All SOE CS gap **+2.01 pp**（旧 +2.10）、PersistentGood **+2.04 pp**（旧 +1.87），仍显著 >0（p<0.001）。
4. 沪深300 依旧无稳健缺口：Full +0.07 pp、CS gap **-1.06 → +0.01 pp**，均不显著；中证500/中证1000 的 CS（+1.48 / +1.86）与 PersistentGood（+1.68 / +2.22）仍显著为正。
5. 金额缺口分解发生重大变化：2025 All SOE 外推区金额占比 **62.2% → 17.7%**（CSI300 103.7% → -10.6%、CSI500 62.8% → 24.6%、CSI1000 40.6% → 23.7%）；总金额缺口 7,559.5 亿元完全不变，仅在不同支撑类别间的分解改变。

**一句话**：论文的率差核心结论（SOE 约 +2 pp 反事实缺口）对共同支撑口径稳健；但正文中「外推区占金额缺口约 62%」的金额化表述对 support 口径高度敏感，采用 5-NN-vs-5-NN 后降至约 18%，需作者决定采用哪一版口径。
